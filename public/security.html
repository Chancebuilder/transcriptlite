TranscriptLite Security

Effective October 4, 2026

Design principle: minimize transcript exposure. Current PDF extraction is intended to occur locally in the browser, while public education-reference lookups use the Education Data Core.

Protecting your information

Do not upload or enter Social Security numbers, passwords, banking credentials, full payment-card data, or information unrelated to degree planning. Redact unnecessary student identifiers from academic documents when practical.

Local device risk

Coursework retained in browser local storage is only as private as the browser profile and device. Use a trusted device and clear stored information when using a shared computer.

Reporting security issues

Report suspected security issues through The Degree Agency's published contact channel. Do not access, alter, retain, or disclose data that is not yours, and do not perform testing that degrades availability. This page is not authorization for intrusive security testing.
